# kashmaromar.github.io

Personal academic website of Omar Kashmar. This is a static site with no build step, built on the [Strata](https://html5up.net/strata) template by HTML5 UP (CC BY 3.0).

## Edit
- Everything is in `index.html`. Search for `TODO` to find the placeholders.
- `images/avatar.png` is your profile photo (square). `images/bg.png` is the sidebar background.
- University logos go in `images/logos/`.

## Preview locally
```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
